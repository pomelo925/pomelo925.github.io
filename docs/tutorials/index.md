# Tutorials

Most of the tutorials would work on Linux OS, which is the optimal OS for developing.

This section is organized into three main categories:

## I. Software
Covers software development fundamentals including Linux system administration, networking protocols, version control, containerization, and DevOps practices.

## II. Robot
Focuses on robotics development with ROS2 (Robot Operating System 2) and simulation platforms like Isaac Sim.

## III. Hardware
Explores hardware development including microcontroller programming with STM32 and PCB (Printed Circuit Board) design.

Choose a category from the navigation menu to explore specific topics and their current development status.
